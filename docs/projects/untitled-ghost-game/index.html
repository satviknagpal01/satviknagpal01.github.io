Untitled Ghost Game

A game jam project where players switch between human and ghost states to overcome obstacles — each form has distinct physics behaviour and interaction rules. Placed Top 5 and was invited to showcase at an industry event.

Stack
C# Unity

Key Achievements

  • ▶Designed and implemented a dual-form mechanic with fully distinct physics and interaction systems per state — core to all of the game's puzzle design
  • ▶Invited to showcase at an industry event as a Top 5 game
  • ▶Shipped a complete, polished experience within the jam's 48-hour constraints

A game jam project built around a dual-form mechanic: players switch between a solid human form and an intangible ghost form to navigate obstacles. Each form interacts with the environment differently — the human obeys normal physics and can push objects; the ghost passes through certain surfaces but cannot interact with physical elements.

The game was invited to be showcased to industry leaders as a Top 5 entry.
