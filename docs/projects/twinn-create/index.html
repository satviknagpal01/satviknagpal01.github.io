At Tooliqa I was a core engineer on two commercial Unity products: Twinn Create (a design and modelling tool) and Twinn Vision (a real-time interior visualiser).

Runtime Mesh Editing

Twinn Create required users to manipulate 3D geometry at runtime — extruding faces, flipping normals, and adjusting parametric dimensions. I implemented these operations by directly reading and writing Unity Mesh data structures, handling winding order, UV re-projection, and normal recalculation after each edit.

Twinn Vision — Material & Furniture Preview

The visualiser needed real-time material swaps (texture, colour, roughness) and furniture model swapping within a pre-built scene. I built the preview pipeline using Shader Graph for the material previews and a scene management layer for asset loading and placement.

CV Debugging Tools

The Computer Vision team worked with spatial data that frequently had alignment errors when imported into Unity scenes. I built a set of Unity Editor tools that visualised misalignment, let engineers mark and correct bad data, and validated the fixed output — reducing their QA iteration cycle significantly.
